# CSV 라벨링 모범 예시: 논문마다 3문항

**n=3으로 정했다. 논문 3편 × 모범 문항 3개 = 총 9개**다. 모두 실제 수집한 PDF의 표·본문과 대조해 답·이유·조건·위치를 채운 교육용 작성 예시다. 두 사람의 독립 검수를 마친 연구용 gold는 아니며, 모든 예시는 `교육용_독립검수전`, `최종gold여부=false`, 검수자 빈칸으로 둔다. 영어 논문 2편과 한국어 논문 1편이며 생물다양성은 비AI 주제다.

## 무엇부터 열면 되는가

1. **[answer_examples.csv](answer_examples.csv)**: 논문마다 질문·판정·모범답변·이유가 3개씩 있다. 아래 9개를 모두 채워 놓았다.
2. **[evidence_examples.csv](evidence_examples.csv)**: 답변에 등장하는 근거 ID의 원문 위치·조건·지표·값을 확인한다. 근거는 총 10행이다. BatchNorm의 본문 반복 위치를 따로 남겨 이 논문만 4행이며, 모범 문항 수는 각 논문 3개로 같다.
3. **[relation_examples.csv](relation_examples.csv)**: 각 논문에서 그림/표와 본문이 같은 결과를 재서술한 관계 1개씩, 총 3개를 보여 준다. 위치 두 곳을 결과 두 개로 세지 않는 연습이다.
4. 실제로 작성할 때는 모범 답안을 보며 베끼지 말고 아래 **빈 CSV**를 검수자별로 복사한다. 연습에 쓴 이 공개 예시를 IAA나 숨겨진 test에 재사용하지 않는다.

CSV는 UTF-8 BOM·LF로 저장했다. `;`는 근거 ID 나열, `+`는 한 충분근거 조합이다. 단위·원문 표기와 ID를 유지하며 저장한다. 서술형 결과도 `값·결과서술` 칸에 적을 수 있다.

## 채워 둔 모범 문항 9개

| 논문 | 문항 | 판정할 내용 요약 | 모범 판정·답의 핵심 |
|---|---|---|---|
| BatchNorm / `ioffe15` | BN-Q01 | BN-Baseline의 목표 정확도 도달 step이 Inception의 절반 미만인가? | **지지**. 1,330만 < 3,100만÷2. 같은 Figure 3 열을 비교 |
| BatchNorm | BN-Q02 | BN-x5는 BN만 추가하고 나머지 설정은 유지했는가? | **반박**. 초기 학습률 0.0015→0.0075와 추가 설정 변경 |
| BatchNorm | BN-Q03 | 210만 step은 seed를 달리한 3회 실행의 평균값인가? | **정보 부족**. Figure 3·§4.2.2의 보고값만으로 반복·집계 정보를 확인할 수 없음 |
| 생물다양성 / `mora2011` | MORA-Q01 | 지구 진핵생물 예측 874만종·SE 130만종을 보고했는가? | **지지**. Table 2의 Eukaryotes Total / Earth / Predicted·±SE |
| 생물다양성 | MORA-Q02 | Table 2와 Results의 874만종은 별도 결과 보고 단위 두 개인가? | **반박**. Results가 같은 예측을 설명하며 Table 2를 직접 참조 |
| 생물다양성 | MORA-Q03 | 해양 예측 옆 ±182,000은 95% CI로 표시됐는가? | **반박**. 열 제목은 ±SE이며 표준오차를 뜻함 |
| 한국어 형태소 분석 / `min2024` | KO-Q01 | 6계층·256차원의 음절 정확도는 97.06%인가? | **지지**. Table 3 해당 행·열과 §4.5 |
| 한국어 형태소 분석 | KO-Q02 | 표와 본문의 97.06%는 별도 결과 보고 단위 두 개인가? | **반박**. 같은 모델·지표·결과의 반복 서술 |
| 한국어 형태소 분석 | KO-Q03 | Table 2의 10.82%는 음절 정확도인가? | **반박**. KorBERT 대비 파라미터 수 비율 |

판정은 고정된 조건·원문 범위에 대한 것이다. `정보 부족`은 확인하지 못한 내용을 거짓으로 단정하는 `반박`과 다르다. `혼재`는 검수자 의견 불일치가 아니라 조건을 맞춘 지지·반박 근거가 공존하는 경우다. 이번 소량 예시에서 확인하지 못한 관계·판정을 채우려고 원문 내용을 만들지 않았다.

## 사람이 실제로 제출할 빈 양식

| 파일 | 작성 단위 |
|---|---|
| [evidence_blank.csv](evidence_blank.csv) | 질문 관련 근거 하나당 한 행: 위치·대상·조건·지표·값 |
| [relation_blank.csv](relation_blank.csv) | 근거 쌍당 한 행: 동일 결과/새 결과/일부 재사용/확인 불가와 이유 |
| [answer_blank.csv](answer_blank.csv) | 문항당 한 행: 판정 명제·조건·답·근거 조합·대안 |
| [adjudication_blank.csv](adjudication_blank.csv) | 제출 후 조정자가 불일치와 최종 사유를 기록 |

R1/R2는 각자 별도 폴더에 빈 CSV 3개를 복사하고, 원문·질문·공통 규칙으로 독립 작성한다. **출제자의 잠정 정답과 상대 답은 보지 않는다.** 작성자·R1·R2와 다른 조정자가 원문으로 불일치를 검토한다. 최초 CSV와 조정 기록은 모두 보존한다. 교육용 예시의 작성자·상태를 실제 사람 이름·검수 완료로 일괄 치환하지 않는다.

같은 숫자만 보고 같은 결과라고 결정하지 않는다. 다른 DOI·저자만 보고 새 결과라고 결정하지 않는다. 지표·표 셀·시드·논문 수를 독립 실험 수로 자동 세지 않는다. 결과 단위의 경계를 질문별로 먼저 정하고, 관계를 확정할 원문이 없으면 확인 불가를 유지한다. 한 문단의 기존/새 결과가 섞였으면 근거를 나누어 기록한다.

확인 불가의 결과 그룹은 null로 두며, eligible 계보가 미확인인 triplet은 확정 GLRS에서 제외·제외율 보고 대상으로 둔다. `정보 부족` 문항의 `확인근거ID`는 읽어 본 범위이고 충분 정답 근거 집합과 다르다. 따라서 해당 행의 `충분근거조합`은 비웠다. CSV를 evaluator JSON으로 자동 변환하는 기능은 포함하지 않았다.

## 원문과 범위

논문별 저자·버전 식별용 원본 해시·출처·이용조건은 [sources.csv](sources.csv)에 있다. 저장소에서는 원문이 상위 폴더의 `raw/`에 로컬 보관된다. 공유 tar에서는 `papers/01_EN_AI_BatchNorm.pdf`, `papers/02_EN_Biology_Species.pdf`, `papers/03_KO_POS_Tagger.pdf`로 제공된다. 쪽수는 PDF 첫 페이지를 1로 센 번호다.

PMLR 역사적 PDF의 개별 라이선스 버전은 미확인, 생물다양성 논문은 Attribution 버전 미표시, 한국어 논문은 CC BY-NC 3.0이라는 기존 권리 기록을 유지했다. 세 논문은 서로 무관한 분야의 수집·주석 연습 예시다. 실제 계보 benchmark에는 관련 원 논문·후속·인용 문헌을 추가 수집해야 한다.
